# DIAMA × PANIC · 04.12.2026
Extrae el paquete y abre index.html. Para GitHub Pages sube los archivos extraídos a la raíz del repositorio y selecciona la rama y la carpeta raíz en Settings → Pages.

El endpoint de Formspree está configurado en config.js. El formulario envía nombre, Instagram, evento y token. El boleto PNG aparece tras la respuesta satisfactoria de Formspree. El mismo navegador puede recuperar su boleto y reintenta envíos pendientes con el mismo token.

En puerta, escanea el QR como texto y coteja el token con los registros recibidos en Formspree. Registra los tokens usados en una sola lista de acceso. El PNG por sí solo no controla el reingreso.

Se conserva el collage original y se usa Blossom Sakura Demo del archivo suministrado. QRCode for JavaScript por Kazuhiko Arase, licencia MIT (incluida en qr.js).

El botón Entrar al registro inicia irukai (ambience) en bucle al 30 %. La cabecera incluye volumen y silencio.
